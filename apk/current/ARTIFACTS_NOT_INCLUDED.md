# Authentic artifacts not included

The following current-release files were not accessible as local bytes when this snapshot was created:

- `FaceBatch-0.7.0.apk`
- `FaceBatch-0.7.0-source.zip`
- the original byte-identical 0.7.0 build report

Expected SHA-256 values are recorded in `SHA256SUMS.txt`.

A placeholder APK would be dangerous because it could be mistaken for an authentic signed release. A rebuilt APK from the 0.4.0 archive would also be materially incomplete. For that reason, this snapshot records absence explicitly and preserves the recoverable historical source separately.
